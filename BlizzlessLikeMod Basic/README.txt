BlizzlessLikeMod (basic edition)
---
Version: 1.0
---
Installation:
1. Put the mods folder next to D2R.exe.

If you are asked to replace files, it means another version of this mod is already installed.
In that case, go to Diablo II Resurrected/mods and delete the existing BlizzlessLikeMod folder there, then copy the mods folder that is next to this file.

2. Run prepare.bat.

It will copy your settings, saves, loot filters, and other data to the correct folder so you don’t lose anything.
You will never need this batch file again — once everything works, you can delete it.

Important!
If you previously played with another mod, manually move the contents from %USERPROFILE%\Saved Games\Diablo II Resurrected\mods\YOUR_MOD to %USERPROFILE%\Saved Games\Diablo II Resurrected\mods\BlizzlessLikeMod.

3. Add this to the game launch options:
-mod BlizzlessLikeMod -txt
If you want infinite offline respecs (for build testing), use these launch options:
-mod BlizzlessLikeMod -txt -enablerespec

4. Launch the game!
