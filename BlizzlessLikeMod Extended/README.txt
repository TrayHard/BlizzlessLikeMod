BlizzlessLikeMod (extended edition)
---
Version: 1.0.2
---
Installation:
1. Put the mods folder next to D2R.exe.

If you are asked to replace files, it means another version of this mod is already installed.
In that case, go to Diablo II Resurrected/mods and delete the existing BlizzlessLikeMod folder there, then copy the mods folder that is next to this file.

2. Run prepare.bat.

It will copy your settings, saves, loot filters, and other data to the correct folder so you don’t lose anything.
You will never need this batch file again — once everything works, you can delete it.

Important!
If you previously played with another mod, manually move the contents from %USERPROFILE%\Saved Games\Diablo II Resurrected\mods\YOUR_MOD to %USERPROFILE%\Saved Games\Diablo II Resurrected\mods\BlizzlessLikeMod.

3. Add this to the game launch options:
-mod BlizzlessLikeMod -txt
If you want infinite offline respecs (for build testing), use these launch options:
-mod BlizzlessLikeMod -txt -enablerespec

4. Launch the game!

---

Changes:
- Skip intro videos when starting the game
- More concise and color-coded names for potions, scrolls, tomes, and gold piles
- Higher runes, as well as statues and shards are more clearly highlighted in item names; shards also show their corresponding acts
- Light pillar highlight for runes (from Lem), uber keys, essences and tokens, shards, and statues
- Quick potion purchase fix
- Diablo-style font fix for chat and higher-value gems
- Buttons for quickly entering a game directly on the desired difficulty
- Separate custom image for each uber key type
- Unique rings and amulets also have individual images (except those newly added in RoW)
- Town NPCs are highlighted above their heads with a unique icon (one per NPC)

---
Colored Modifiers

Additionally, you can install color-coded item modifiers to make them easier to read.
To do this, copy the contents of the `colored modificators` folder into your game folder and replace files when prompted. To revert, simply reinstall the entire mod.
